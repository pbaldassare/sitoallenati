# Sito Allenati

Landing page di [Allenati.me](https://allenati.me), l'app per palestre e centri fitness.

Pagina statica: `index.html`, `styles.css`, `script.js`, cartella `assets/`. Nessuna build.

## Anteprima in locale

```bash
python3 -m http.server 8765
```

Poi apri <http://localhost:8765>.

## Pubblicazione

Il sito è servito da GitHub Pages dal ramo `main`, cartella radice.
